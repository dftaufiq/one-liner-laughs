A single funny line of at most 200 characters, written to `/output/entry.txt` by a small deterministic TypeScript program for make.fun's "One-Liner Laughs" bounty. The line is a two-beat joke with the reveal in its final clause: a buried goldfish, a son checking whether heaven has Wi-Fi, and a second lie about the farm.
